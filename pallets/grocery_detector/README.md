# grocery_detector

Custom on-device grocery item detector for ZikZak — 20-class TFLite image
labeler (no object-detection training) aligned with the app's embedded
grocery dictionary. See [SPEC.md](SPEC.md) for the full agent brief.

> Private-repo dependency: the target app is `github.com/arrrrny/zik_zak`
> (branch `060-photo-grocery-price-compare`); ML Kit packages come from the
> `arrrrny/zikzak_ml_kit_flutter` fork (`ref: spm-fixed`).
